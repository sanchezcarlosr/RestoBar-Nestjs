## Description

[Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```

## Dependecies
En este proyecto se aplica una estructuración del proyecto siguiendo los principios SOLID
Ademas se decidio aplicar una arquitectura basada en eventos para mejorar el desacoplamiento y asilando efectos secundarios, evitando dependencias directas entre modulso, mediante las siguientes dependencias que NestJs ya provee:
```bash
$ npm install @nestjs/event-emitter
```
Este paquete permite crear eventos que NestJS lo engloba en su configuración al levantar el proyecto
permitiendo hacer una llamada al evento para ejecutar su logica

Otro paquete que se usa para porner en practica la creación de eventos es nodemailer:
```bash
$ npm i @nestjs-modules/mailer
$ npm i nodemailer
```

## Cloudinary
Otra de las dependencias para guardar imagenes. Las configuraciones estan la carpeta Shared/cloudinary
ya que sera utilizado para varios modulos que requieran subir imagenes.
Sus dependencias son:
```bash
$ npm i cloudinary
$ npm i streamifier
$ npm i -D @types/streamifier
$ npm i -D @types/multer
$ npm i -D @types/streamifier
```
Estos paquetes son requeridos para que se ejecuten.
